# Habit Tracker

## Description
Habit Tracker is a simple application to help users track their daily habits, set goals, record streaks, view history, and see progress statistics.

## Features
- Track daily habits
- Set goals
- Record streaks
- View history
- Progress statistics
- Notifications and reminders
- Share progress on social media
- Integration with other apps

## Installation
1. Clone the repository
2. Run `npm install`
3. Create a `.env` file based on `.env.example`
4. Run `npm start`

## Usage
1. Register and login
2. Add new habits
3. Mark habits as completed
4. View progress and statistics
